# genesis-nav Documentation

`genesis-nav` is a ROS 2-native embodied runtime infrastructure project for
Genesis World. It focuses on runtime control, multi-agent simulation, replay,
observability, and future real-robot deployment.

Start here:

- `architecture.md`: runtime boundaries and module responsibilities
- `interfaces.md`: public ROS 2 and runtime contracts
- `experiments.md`: reproducible scenario and benchmark history
- `decisions.md`: lightweight architecture decisions
- `roadmap.md`: v0.1 and staged development plan
- `ai_agents.md`: the AI tool API contract and safety boundary
- `humanoid.md`: the humanoid navigation-intent shell and non-goals
- `benchmarks.md`: benchmark suites, expectation predicates, and the harness
- `replay.md`: the run-directory replay contract
- `../PLAN.md`: detailed v0.1 implementation plan

Contributor surface:

- `../CONTRIBUTING.md`: setup, tests, PR expectations, and safety boundary
- `contributing_scenarios.md`: scenario / benchmark contribution rules
- `good_first_issues.md`: ten curated starter tasks
- `demo_script.md`: recording script for the README GIF and launch video
- `launch_posts.md`: draft posts for ROS Discourse and the Genesis community
