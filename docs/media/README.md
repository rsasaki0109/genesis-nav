# Media

Binary demo assets for `genesis-nav`.

- `smoke_demo.gif` — README hero clip of `gnav run`, run artifacts,
  replay, and bench.
- `smoke_demo.cast` — raw asciicast used to generate the GIF; kept so
  the next recording can be diffed instead of re-shot from scratch.

Regenerate with `make demo-gif` (requires `asciinema` and `agg`; see
`docs/demo_script.md` and `scripts/make_demo_gif.sh`).

`walkthrough.mp4` (or YouTube link) for the long-form 2-minute demo is
hosted off the repo — see `docs/launch_posts.md`.

Keep this directory under ~10MB total. Larger captures should be hosted
off the repo and linked.
